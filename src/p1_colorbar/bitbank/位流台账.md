## 编译方式（本版实测有效）

TD 6.2.1（6.2.168116）。**命令行 `launch_runs` 在本机不可靠（会假成功），用 `DefaultFlow.tcl` 同步流程**：

```bash
# 1) 综合：在 syn_1 目录跑
cd .../OUR_p1_colorbar_Runs/syn_1
td_commands_prompt.exe <TD安装>/doc/scripts/DefaultFlow.tcl

# 2) 布局布线 + bitgen：在 phy_1 目录跑
cd .../OUR_p1_colorbar_Runs/phy_1
td_commands_prompt.exe <TD安装>/doc/scripts/DefaultFlow.tcl
```

**三个坑**（本次实测踩到）：
1. `launch_runs` 报 `PRJ-1410 Run success` 但实际 `run.exe` 没跑（假成功）→ 改用 `DefaultFlow.tcl`。
2. `open_project` 生成的 `settings.cfg` 里 `device_name`/`package_name` 为空 → 手动补 `ph1_35p.db` / `PH1P35MDG324`。
3. `phy_1` 目录需要从 `syn_1` 复制 `.prj`，否则 `open_project -noanalyze` 失败。

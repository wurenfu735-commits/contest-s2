## 上板验收清单

| # | 操作 | 期望现象 | 若不对说明什么 |
|---|---|---|---|
| ① | 插好 SC520 摄像头 + HDMI + Type-C，Program SRAM 烧 `OUR_K1_4mode.bit` | 720p 彩色实时画面，左上角有安路 Logo 与 `安路 CNT:` 计数（OSD 沿用官方通路） | 全黑 / 全灰 → 先确认烧的是哪块位流（比对 SHA256），再查摄像头排线 |
| ② | 按板载 **KEY1（D5）** | 原图 → 灰度 → 中值 → 边缘 → 原图，每按一次前进一档 | 按了没反应 → 注意板载 KEY1 与排针 `I_button`（N2/J14）是两回事，本工程用板载 KEY1 |
| ③ | 长按 KEY1 不放 | **不连跳**，松开稳定后才接受下一次按下 | 连跳 → 消抖或边沿检测有问题 |
| ④ | 灰度模式看白纸 / 黑物 | R=G=B，黑 0 白 255 | 仍是彩色 → 烧错位流 |
| ⑤ | 中值 / 边缘模式看暗部平坦面 | 雪花应比原图明显减少 | 依旧满屏雪花 → 阈值偏低，需按真实场景重标定 |
| ⑥ | 边缘模式对桌面、暗墙、物体轮廓移动 | 黑底白线，弱边可辨，无连片假边 | 连片假边 → 阈值偏低 |
| ⑦ | 连续运行 30 分钟 + 强光/暗光切换 | 无横条、撕裂、闪黑、卡死 | 有 → 记下现象与光照条件再定位 |

> 仿真与编译不能替代上板结论：`sim/` 下的验证日志是 Python 独立黄金模型对 RTL 的**逐像素**比对（四模式各 1280×720，921,600 组 / 3,686,400 像素全部一致），但不代表已模拟完整加密的 MIPI / DDR / HDMI PHY。

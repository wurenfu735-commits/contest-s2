## 二、关键实测数据（口径已统一）

> ⚠️ 历史文档出现过 78.76% / 78.57% / 78.32% / 77.55% 四个数字（综合 vs P&R、官方 vs 自研 OSD 混用）。
> **今后一律用下表**，引用时必须写明是哪套 OSD。

| 项目 | 官方 OSD（现行） | 自研 OSD（待切换） |
|---|---|---|
| Slice（**P&R**） | 16,616 / 21,216 = **78.32%**（余 358） | 14,654 = **69.07%** |
| Setup WNS | +0.005 ns | **+0.787 ns** |
| OSD 模块开销 | `u_hdmi_mixer` 2,753 LUT | `u_osd_overlay` 593 LUT |
| ERAM | 60~63 / 108 | 🟢 充裕 |
| DSP | 9 / 40（**剩 31**） | 🟢 充裕 |

- 算法 `u_edge_adaptive_96`（v5）：LUT ~3200 · FF ~650 · ERAM ~30 · **DSP 0**
- P0 官方基线：Slice 58.40% · SWNS +1.242 ns · 0 违规

> 🔑 **我们缺的是 Slice，不是 DSP**（DSP 只用 22.5%）。所以"kernel 全展开成移位加法做到 0 DSP"
> 那套经验对我们是**负优化**——省 DSP 换更多 LUT，正好打在唯一短缺的资源上。

## 五、三条重要约定

**1. 工作区约 481 MB，其中只有约 97 MB 进版本库。** 大块头都在 `.gitignore` 之外：
`assets/ref_docs/` 237 MB · `assets/ref_videos/` 54 MB · `OUR_project/` 109 MB · `sim/golden/out/` 60 MB。

> 历史教训：曾有单个 `vsim.wlf` 长到 **26 GB**，工作区一度 27.7 GB。`.gitignore` 就是为此设的。
> **不要为了让产物进仓库而删 `.gitignore` 规则**——仓库会瞬间膨胀，push 必然失败。

**2. 位流走 GitHub Releases，不进 git。** 每个 `.bit` 约 1.7 MB。
**判断哪个是现行版看 `位流台账.md` 的「★ 现行版本」，不要看文件名**——同阶段位流字节数几乎相同。

> ⚠️ **待你拍板的冲突**：`.gitignore` 里有 `!src/p1_colorbar/bitbank/*.bit`（例外：位流入库，便于 `git clone` 直接拿到），
> 与本条"位流不进 git"矛盾。2026-10-19 整理时已把 8 个位流从版本库移出（现为 untracked），
> 但规则还留着——下次 `git add -A` 会再加回来。**二选一：删掉那条例外，或把本条改成"现行位流入库"。**

**3. 第三方参考资料不随本仓库分发。** `assets/ref_docs/guoyi_repo*` 是他人 2025 年国一作品的开源副本，
有独立来源与许可，按 `docs/05`（已归档）里给的 GitHub 地址自行获取。

## 六、红线（来自赛题规则）

1. 官方例程的**算法禁止照抄，必须自研** —— 我们的算子是"5×5 盒式平滑 + 基线 2 中心差分的等效 5×7 可分离梯度"，
   与官方 3×3 Sobel **不同族**（详见 `docs/算法规格.md`）。
2. **外扩电路板不得含非安路 FPGA**；**不得外挂额外处理器**（ESP32 / Arduino / 树莓派出局，PC 不能跑算法）。
   片内 RISC-V 硬核可用（在 FPGA 内）。
3. **必须用 TD 6.2.1**（高版本不向下兼容）；作品须原创。

## 八、诚实结论（答辩要讲）

- ✅ 摄像头 → ISP → DDR → HDMI 通路正常，自研算法替代官方边缘检测，**轮廓清晰、画面实时**
- ⚠️ 平面上**仍有残留雪花**：传感器暗场噪声经 awb 增益放大后被边缘检测显性化。
  治理路线已定：**L2 暗区增益限幅（治本）+ L3 行列可分离 3 抽头中值（治标）**，见 `docs/算法规格.md` §1.1
- ⚠️ A2 位流内含 **v1 旧算法**，已被 v5 取代，待重新综合后废弃旧版
- ℹ️ **上板看到黑白画面是设计行为，不是故障**：边缘模式下是二值输出。
  要看彩色原图，把 `design_top_wrapper.v` 的 `I_mode` 改为 `2'd0`（或按 KEY1 切到模式 0）。

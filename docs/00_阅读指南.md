- **新人上手**：`00` → `01`（题目是啥）→ `07`（怎么干）→ `03`（怎么上板）→ `12`（现在做到哪了）

- **要上板验证**：`03`（编译烧写速查）→ `位流台账.md`（烧哪个、该看到什么）

## 五、文档约定

1. **编号即主题**（01 赛题 / 02 规划 / 03 编译 / 04 例程 / 05 调研 / 06 情报 / 07 路线 / 08 算法 / 09 问题 / 10 协作 / 11 复用清单 / 12 阶段总结），新文档按主题接续编号。
2. **过期文档移入 `archive\`**，不直接删除（留痕）。
3. **一次性报告**（日终收尾等）写完即归档，不作为长期参考。
4. 引用其他文档用相对链接（`./XX_名称.md`），不要写绝对路径。
5. **文档必须与仓库实际一致**：文中提到的路径、文件名、数量都要能在仓库里找到；
   结构调整后（如 tb 重组、目录改名）要同步更新引用本文档的链接。

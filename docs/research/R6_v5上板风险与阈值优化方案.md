# R6 · v5 上板风险预判与阈值优化方案

> 背景：v5 已把暗区地板从 192 下调到 144（修复"暗环境检测不出来"），代码与位流就绪，
> **尚未上板验证**。本文在推进前预判上板可能出现的常见问题，并给出优化方案。
> 状态：调研完成（结合公开的 Sauvola/Niblack 局部自适应阈值算法），未改代码。

## 一、v5 改动的本质与根本风险

```
v4 暗区地板 192 → v5 144
  目的：让 Δ≈8~12 灰度级的弱边能检出（v4 在暗区 Δmin≈19.2，几乎检不出弱边）
  代价：门槛降低 25% → 真实传感器噪声更容易越过阈值 → 残雪可能回潮
```

**一句话风险**：v5 用"降低全局地板"换"暗区弱边检出"，而**固定地板无法区分"弱边"和"噪声"**——
这两者在灰度梯度幅值上是重叠的。队友的仿真（σ=4）显示虚警 0%，但**真实暗场经 awb 增益后
σ 可能到 6~10**，队友注释自己也写了"σ=6 时 v4 自身虚警都守不住"。

## 二、上板可能出现的常见问题（按概率排序）

| # | 问题 | 现象 | 根因 |
|---|---|---|---|
| **1** | **暗区雪花回潮**（最可能） | 暗处弱边出来了，但平坦暗区出现细碎白点 | 地板 144 低于真实噪声梯度（σ≥6 时） |
| 2 | **分段边界跳变** | mean25 落在 64/128/192 边界附近时，画面出现横向"阈值台阶"假边 | 四段地板每段差 12（144→132→116→96），边界处阈值突变 |
| 3 | 边缘加粗/粘连 | 弱边检出后，迟滞弱门（thr>>1）把相邻噪声点连成片 | 地板下调连带弱门一起降 |
| 4 | 亮暗过渡区噪声 | 暗区靠近亮区的过渡带出现噪声 | 过渡区 mean 落在分段边界，地板与噪声关系失配 |

## 三、优化方案（四个候选，从"最小改动"到"治本"）

### 方案 A（治本，推荐）：噪声自适应阈值（Sauvola 简化）

**核心思想**：用**局部标准差**替代/补充固定地板，让阈值**随噪声自动摆位**：

```
Sauvola 原始：  T = mean × (1 + k × (std/R − 1))
我们可用的简化：thr = FLOOR_下限 + k × dev
                 dev = Σ|x − mean| / N    （局部平均绝对偏差，近似 std，无乘法器）
```

**为什么它能解决 v5 的两难**：

| 场景 | mean | dev（噪声/波动） | 结果 |
|---|---|---|---|
| 暗区平坦（有噪声） | 低 | 大 | thr 抬高 → **压噪声** ✅ |
| 暗区有弱边 | 低 | 大（边缘贡献） | thr 抬高，但边缘 mag 更大 → **仍检出** ✅ |
| 亮区平坦 | 高 | 小 | thr 回落 → 保细节 ✅ |

**硬件成本**：我们**已经算了 S1..S4（5×5 和）得到 mean**，只需再加一个"5×5 窗口内
|x−mean| 求和"（25 个减法 + 绝对值 + 加法树）→ **复用现有窗口数据，增量约 +200~300 LUT，0 DSP**。

**落地**：`thr = FLOOR_下限(如 48) + k*dev`，`k` 作参数可调。这比 v5 的"四段固定地板"更本质——
从"分段常量"进化到"逐像素噪声自适应"，正是我们最早讨论的"自适应应该自适应噪声，而非亮度"。

### 方案 B（省资源备选）：3×3 中值滤波前置

- 点状噪声的正规军，比均值更保边
- 把噪声在进梯度前抹掉，地板就能放心下调
- 成本 ~600 LUT；改动在灰度化后、行缓存前，需重新仿真

### 方案 C（最小改动）：真实噪声标定驱动地板

- 用 ChipWatcher / UART 行统计拿**真实噪声-亮度曲线**
- 把四段地板设到"刚好压住 3σ 噪声"的位置（现在是队友按理想 σ=4 推的）
- 不改算法结构，只改 4 个常量；v5 已有 `THR_ADD_D0..D3` 参数，改值即可

### 方案 D（微调）：迟滞弱门收紧

- 弱门从 `thr>>1` 改为 `thr*3>>2`（75%），减少噪声经迟滞的放大
- 一行改动，与 A/B/C 可叠加

## 四、推荐路线（先上板，再按现象选方案）

```
1. 先上板 v5（现行位流 OUR_b4osd_v5_darkfloor.bit）
   → 记录：暗区弱边是否出来、平坦区是否有雪花、OSD 是否正常
        ↓
2. 按现象选方案：
   · 弱边出来 + 无雪花        → ✅ v5 直接过，转下一项
   · 弱边出来 + 雪花回潮      → 方案 C（标定）快速顶一下 → 方案 A（Sauvola）做 v6
   · 弱边没出来              → 地板还不够低，或算法有 bug（先跑仿真排除）
        ↓
3. 本机跑 RTL 仿真（补上队友没 ModelSim 的缺口），确认 v5 逻辑无误差后再上板
```

## 五、一句话结论

**v5 的"暗区地板下调"是对的方向，但固定地板有天花板——它无法区分弱边和噪声。
下一版（v6）的正解是方案 A：把阈值从"分段常量"升级为"逐像素噪声自适应（Sauvola 简化）"，
硬件上只是复用现有 5×5 窗口加一个绝对偏差和，成本极低。**

先上板看 v5 的真实现象，再决定要不要上方案 A。

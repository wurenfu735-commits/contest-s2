# R7 · 场景鲁棒性深度调研：统一解决"噪点多"与"近远不可兼得"

> 背景：v5 上板实测显示"基本边缘检测可用，但①噪点很多（尤其暗区）②调焦距时近/远效果不可兼得"。
> 两个现象本质都是**"固定阈值无法感知场景差异"**。本文围绕"自适应调节（适应光照/噪
> 声/模糊场景）"做调研，给出统一解法（不开工，只调研）。

## 一、两个现象的本质是同一个根因

```
噪点多   → 暗区平坦处有噪声，v5 地板 144 低于真实噪声梯度 → 误检
近远不可兼得 → 离焦模糊降低边缘梯度，导致原本该检出的边低于阈值 → 漏检
```

| 维度 | 噪声区（平坦暗面） | 离焦模糊区（软边） | 锐利边缘区（正常） |
|---|---|---|---|
| 局部均值 mean | 低 | 低-中 | 中-高 |
| 局部标准差 s | ↑ 大（噪声贡献） | ↓ 小（低频平滑） | ↑ 大（边缘贡献） |
| v5 固定地板 | 144（一刀切）| 144（一刀切）| 144（一刀切）|
| 我们需要的 | **更高**（压噪声）| **更低**（保模糊边）| 适中 |

**两个场景需要的阈值方向相反**——固定地板（无论分几段）永远无法同时满足。

## 二、Sauvola 局部自适应阈值：一个公式同时解决两个问题

**原始公式**（Sauvola 2000，"Adaptive document image binarization"）：
```
T(x,y) = m(x,y) × [1 + k × (s(x,y)/R - 1)]
```
其中 m=局部均值，s=局部标准差，R=标准差归一化参考值（通常 128），k=调节系数（0.2~0.5）。

**为什么它能统一解决**：阈值由 m 和 s 两项共同决定，而 s 恰好对"噪声"和"模糊"给出
**相反的响应**：

| 场景 | s 的变化 | T 的变化 | 效果 |
|---|---|---|---|
| 暗区平坦噪声 | s ↑（噪声高频） | T ↑ **抬门槛** | ✅ 压噪声 |
| 离焦模糊软边 | s ↓（低频平滑） | T ↓ **降门槛** | ✅ 检出模糊边 |
| 锐利真边缘 | s ↑（边缘贡献） | T ↑ 但 mag↑↑ | ✅ 仍检出 |

**与 v5 的本质区别**：v5 是"固定分段地板 + 亮度项"（`thr = floor_section + mean*K`），
地板是常数；Sauvola 是"逐像素的自适应地板"（地板 = `k*s`），s 随场景自动变。

## 三、可硬件实现的简化形式

**省去除法**（/R 用移位近似；m× 乘法用移位与加法）：
```
dev = Σ|x - mean| / N        （局部平均绝对偏差，近似标准差，省平方/开方）
thr = FLOOR_min + k × dev    （FLOOR_min 保证平坦区的 thr 底线）
```

**硬件基础**：我们**已有 5×5 窗口的满数据**（col5 + S1..S4 的 sum25），
需要新增：
- 每像素的 mean（已有：S3 >> 4，近似 /16）
- 每像素的 |x - mean| 求和（5×5 = 25 个减法+绝对值+加法）
- dev = 偏差和 >> 4（近似 /16）
- thr = FLOOR_min + k*dev（移位/加法，k 用 2 的幂次近似）

**成本估算**：每像素 ~25 次减法+绝对值+加法 × 4 像素/拍 ≈ **300~500 LUT**，
0 DSP（k 用移位）。比 v5 的四段 floor_sel（几个比较器）多，但换来的是一套
**不需要调参的场景自适应能力**——这正是"适应不同场景"的正确答案。

## 四、多尺度边缘检测（对"近远不可兼得"的另一个思路）

**离焦模糊**在频域里等价于"低通滤波"——边缘坡宽变大、峰值降低。
大尺度边缘检测（更大的梯度核）对这种宽坡边缘有更好的响应。

| 尺度 | 适合检测 | 不适合 |
|---|---|---|
| 小核（3×3） | 锐利边缘、细节纹理 | 模糊边缘漏检 |
| 大核（5×5） | 模糊边缘、远距离轮廓 | 细小纹理被抹掉 |
| **多尺度融合** | 两者都检 | 硬件翻倍 |

**约束**：我们已有 5×5 窗口（不变），如要再加 3×3/7×7 需要更多行缓存，成本大。

**但可以复用**：同一 5×5 窗口内（col5 数据已经包含了 3×3 子窗口的求和）——
**用中心 3×3 与完整 5×5 同时算梯度，取 max**，不需要额外行缓存。

5×5 窗口内做 3×3 梯度 = 复用现有数据 ✓ 成本低（多一路比较）。

但经分析：Sauvola 的**标准差自适应**已经在"模糊处自动降低阈值"——效果与多尺度
类似但手段不同（阈值自适应 vs 梯度核自适应），且成本更低。**所以多尺度可以作为
Sauvola 不足时的备选，不做第一推荐。**

## 五、光照不变性（Sauvola 的附加收益）

Sauvola 用 `s/m` 或 `s/R` 这个**相对偏差**——亮区 m 高、s 也高；暗区 m 低、s 也低；
但 **s/m** 的比例在不同光照下保持稳定（光照可建模为乘法增益）。

简化版 `thr = FLOOR_min + k*dev` 保留了 `dev`（绝对偏差），虽然没有除法做归一，
但 `dev` 本身在亮暗区间已经**相对稳定**（亮区噪声绝对值更大、暗区更小，与光照增益
大致成比例）——对于"传感器噪声→awb 增益"这条链路，效果优于"固定地板"。

若追求完全光照不变，需要 `thr = m × (1 + k*dev/m)` 用除法——但我们不必到此地步：
`k*dev` 已经比固定地板好得多，实践中够用。

## 六、候选方案对比

| 方案 | 自适应能力 | 硬件增量 | 对两个问题的效果 |
|---|---|---|---|
| **Sauvola 简化**（推荐） | 逐像素噪声/模糊自适应 | ~300-500 LUT | 同时解决噪点多（暗区 s 大→阈高）和模糊漏检（模糊区 s 小→阈低） |
| 多尺度梯度（3×3+5×5 融合） | 模糊自适应 | 低（复用窗口） | 只解决模糊漏检，不治噪声 |
| 前置中值 + 固定地板 | 噪声（点状） | ~600 LUT | 只压噪，模糊仍漏检 |
| 退回 v4 地板（160+） | 无自适应 | 0 | 回避问题，不是解决 |

**结论**：Sauvola 简化版是唯一用一个机制同时覆盖两个问题的方案，且符合"适应不同场景、
光照条件"的价值取向。

## 七、风险与注意

1. **平坦区 dev 可能过小**：当真正的弱边处在完全平坦区时（dev≈0），thr≈FLOOR_min 可能过低
   → 需要 FLOOR_min 底线保护（如 64）
2. **dev 计算延迟**：偏差和比现有的 sum25 多 1 拍，需要对齐流水线
3. **k 参数选择**：需要通过仿真（黄金模型先跑）标定，不能拍脑袋
4. **Sauvola 原始公式里的 R（128）**在简化版里被吸收了，但会影响"暗 vs 亮"的归一化效果
   —— 我们可先用简化版，效果不够再补 R 归一化

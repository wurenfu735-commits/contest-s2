## 一、易灵思项目给我们的核心启发

它的 `Sobeledge_proc.v` 第 156 行，二值化**不用固定阈值**，而是：

```verilog
// 输出三选一：
source_data = edge_en ? 
    (bin_en ? (Gmax >= matrix_p22_dly ? 8'hff : 8'h00)   // 二值化：梯度 ≥ 中心灰度
            : (Gmax > 510 ? 8'hff : Gmax[8:1]))           // 边缘强度：梯度缩放
    : matrix_p22_dly;                                      // 原图
```

两个关键点：
1. **二值化 = `Gmax >= 中心像素灰度`**（自适应，天然抗亮度变化）
2. **边缘强度图 = `Gmax` 缩放**（不做二值化，绕开阈值跷跷板）

## 二、待执行的改造（等综合完）

### 改造 1：二值化方式改为"梯度 ≥ 中心灰度"（自适应）

当前我们的二值化是固定阈值 `mag >= thr0`（I_k 选档），容易跷跷板。
改为：`edge = (mag >= {中心灰度, 若干0})`，即梯度与中心像素灰度比较。

- 中心灰度 = `median`（中值后的灰度），8bit
- mag 是 12bit，需要对齐位宽：`edge = (mag >= {4'b0, median_center})`，或 `mag[11:4] >= median_center`
- 这样暗场景中心灰度小（~20），阈值自动变低；亮场景中心灰度大，阈值自动变高——**自适应**。

### 改造 2：新增"边缘强度灰度图"输出模式（治本）

在 mode 里加一个"边缘强度"模式，输出 `mag` 缩放的灰度图：
```verilog
// mag 12bit → 8bit 灰度：mag 范围 0~2040，缩放到 0~255
out = (mag > 2040) ? 255 : mag[11:4];   // 右移4位，或 mag>510?255:mag[9:2]
```
- 效果：边缘=亮（梯度大），平区=暗（梯度小），噪点=暗（噪点梯度小）
- **彻底绕开二值化阈值**，用户直接看灰度梯度图就能看清边缘

### 改造 3（可选）：8 方向 Sobel

易灵思用 0/45/90/135° 四组方向（对称方向绝对值相同），比我们只用 Gx/Gy 更全。
- 但会多 2 组卷积，资源增加。**先不做**，等前两个改造验证有效再说。

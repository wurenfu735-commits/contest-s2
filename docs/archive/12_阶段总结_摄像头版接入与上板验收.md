## 一、本阶段目标与结论

**目标**：把自研算法 `edge_adaptive_96`（96bit 全分辨率自适应阈值边缘检测）接入官方 SC520 摄像头 → HDMI 通路，生成可上板验证的位流。

**结论**：✅ 完成。算法仿真逐像素 0 误差；综合 ripple>0（未被优化删除）；P&R 时序 0 违规；bit 已生成并归档。
**注意**：本文前半部分记录的是**接入当天的 v1 形态**；随后的 v1→v4 迭代与用户拍板的暂停点见**文末第七节**。

## 三、关键技术数据（答辩可引用）

**仿真**：接入验收当时（v1 形态）用 128×8 干净图案与已验证逐像素版**逐像素完全一致（628 像素 0 误差）**。
**现行验证（v4）**：tb 图案 128×**12**（含 **±3 确定性噪声**，THR_FLOOR=96、I_k=2），一键 `run_tb_96.ps1` 与 v4 黄金模型逐像素比对 **0 误差（PASS）**。

**综合实测**（`gate.area`，**v1 形态**，摄像头版接入当日）：
| 模块 | LUT | ripple | seq | ERAM | DSP |
|---|---|---|---|---|---|
| `u_edge_adaptive_96` | 1134 | **148** | 305 | 11 | 0 |
| 全设计 | 10548 | — | 13990 | 50 | 8 |

> v4 形态（6 块灰度 + 1 块判决行缓存、窗口 10×7）的综合资源**已实测**（2026-10-16 18:58 综合）：LUT 12187 / reg 14384 / slices 4832（22.78%）/ RAMs 63 / DSP 8；P&R 后 slices 14177（66.82%）/ RAMs 60。

**与官方的差异**（赛题红线对应）：

| 分辨率 | 降采样到 640 | 全 1280 |

## 四、踩坑与沉淀（细节见 MEMORY 坑 33–39）

1. 并行流水线行缓存地址必须逐拍推演（坑 33）
2. Verilog 拼接最左是 MSB（坑 34，`upleft` 方向反了是"每行多一对误检"的种子）
3. 验证方法要可靠：按像素编号对齐，别猜偏移（坑 35）
4. 对应模块自身带 +4 标注延迟，对比前量化（坑 36）
5. 行首跨行拍（坑 37）
6. **TD GUI 开工程持锁，外部改 `.al` 被回滚**（坑 38，本次最坑：改完必须关 TD / 等锁释放 / 复查留存）
7. patch 脚本要幂等自包含全部动作（坑 39）
8. 综合期 gate.qor 负 WNS 是布局前悲观值，以 Routed 报告为准（坑 28 补充）

## 七、v1→v4 迭代与暂停点（2026-10-17）

> 位流与上板现象的**唯一权威**是 [`bitbank\位流台账.md`](../../src/p1_colorbar/bitbank/位流台账.md)；
> 每版实测数据与决策记录在 `memory\PROGRESS.md`「算法噪声鲁棒性迭代 v1→v4 与暂停点」。

| 版本 | 算法 | 上板结果 |
|---|---|---|
| v1 | 纯 Sobel + 亮度自适应阈值（FLOOR16/K2） | 满屏雪花（阈值方向写反：暗处最吵却门槛最低） |
| v2 | +3×3 均值去噪 | 轮廓出来、雪仍在 |
| v3 | +5×5 均值去噪（行缓存 3→6 块，窗口 10×7） | 轮廓很清、雪仍未根治 |
| **v4** | **分段 FLOOR**（噪声地板随亮度摆位：暗192/中160/中高128/亮96，基准 THR_FLOOR=96 由 isp_top 传入）+ 亮度项 mean25×K>>5 | **雪花显著变少但仍有残留 → 用户拍板暂停**；模型层：暗区纯平坦假边缘 0%、低对比（台阶14）弱边缘 85.7%；RTL vs 黄金模型 0 误差 |

**暂停时的诚实判断**（不作 accomplishment）：
1. 原图本身有"不明显"的噪点（传感器暗场物理噪声 + awb 增益），边缘检测把它放大成明账；
2. 二次拍摄视频经压缩，无法量出真实噪声-亮度曲线（`tools/archived/analyze_noise_vs_luma.py` 已作废归档）；
3. 官方对比态 `OFFICIAL_THR` 未按 v4 量级重标定 → 分屏对比目前不能引用为定量结论；
4. v4 形态综合资源（2026-10-16 18:58 综合实测 / 19:01 P&R）：全设计 LUT 12187 / reg 14384 / slices 4832（22.78%）/ RAMs 63 / DSP 8；P&R 后 slices 14177（66.82%）/ RAMs 60；时序 Setup WNS +0.376ns / Hold WNS +0.020ns / 0 违规。

**剩余待办**：见第六节；基本功能（物体轮廓清晰、画面实时）已实现，残雪留待后续完善，不算完成项。

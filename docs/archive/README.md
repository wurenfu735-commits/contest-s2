## 为什么有这一堆

项目推进过程中，同一主题的文档会被重写（赛题解读、执行路线图、TD 编译步骤等）。按 `docs/00_阅读指南.md` 的约定，
**过期文档移入本目录而不是删除**，这样才能回溯"当时是怎么想的"。

## 看这些文档要注意什么

| 注意点 | 说明 |
|---|---|
| ⚠️ **相对链接可能失效** | 文档被移入本目录后，`./XX_名称.md` 这类链接指向的位置已经变了 |
| ⚠️ **文件路径可能失效** | 目录结构重构过（如 tb 重组为 `unit/`/`integration/`/`gen/`、位流移入 `archive/old_bit/`），文中提到的路径可能已不存在 |
| ⚠️ **结论可能已被推翻** | 例如旧路线图里的"扩展选 2 个"已经被否掉 |
| ✅ **历史细节仍然有效** | 排查过程、当时的实测数据、被否决的方案理由——这些是第一手记录 |

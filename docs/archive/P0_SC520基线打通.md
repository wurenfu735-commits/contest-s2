# P0 · SC520 基线打通（编译 → 烧写 → 出画面）

> 目标：先让官方 **SC520 例程**在你手上那套板子上跑通，看到**实时视频画面**。
> 这一步是后面所有自研工作的地基——先证明"工具链 + 板子 + 摄像头 + HDMI"整条链是好的。

---

## 0. 一句话验收标准

显示器稳定显示 **1280×720 彩色实时画面 ≥ 10 分钟**，不花屏、不撕裂；随后记录一次资源占用（作为自研的基线对比）。

## 1. 硬件接线（⚠️ 全部断电操作）

| 顺序 | 动作 |
|---|---|
| 1 | 电源开关拨到 **OFF** |
| 2 | 插 **SC520 摄像头** 排线到板子 FPC 接口（注意金手指方向 + 卡扣锁紧，勿折死弯） |
| 3 | 插 **HDMI 线**（板子 HDMI → 显示器） |
| 4 | 插 **12V 电源适配器**（接摄像头+HDMI 负载必须上 12V，别只靠 USB） |
| 5 | 插 **USB 转 JTAG 线**（Type-C → 电脑，用于下载程序） |
| 6 | 开电源，观察数码管/指示灯 |

> 红线：不断电不插拔排线；扩展口是 3.3V，勿接 5V 器件；手先摸接地点放静电。

## 2. 烧写器驱动确认（一次性）

- 打开**设备管理器**，确认出现 **USB Serial Converter A**（VID/PID = `0403:6042`）。
- 若没装 WinUSB：参考已有文档 `E:\workbuddy\fpga\WinUSB驱动安装说明_资料包索引.md`，用 UsbDriverTool 给该设备装 **WinUSB**；`hwserver.exe` 已在 `E:\app\Software\work\td\bin\`。

1. 打开 TD 6.2.1（`E:\app\Software\work\td\td.exe`）。
2. 打开工程文件（**注意 SC520 是双层同名目录**）：

3. 确认器件为 **PH1P35MDG324-3**（若弹器件不匹配提示，以工程为准）。

## 4. 全流程编译

按顺序点（每步跑完再看下一步）：

| 步骤 | 动作 | 通过标志 |
|---|---|---|
| 4.1 | Read Design / 读取设计 | 无 ERROR |
| 4.2 | Optimize RTL / 综合 | 无 CRITICAL WARNING |
| 4.3 | Optimize Gate + Place & Route / 布局布线 | 无时序违规 |
| 4.4 | Generate Bitstream / 生成下载文件 | 生成 `.bit`，**无 BIT-8123** |

> 关键点：工程自带的约束已齐全（`pin.adc` + `timing.sdc`），**不要删改**。
> 若报 `BIT-8123 Bitgen is prohibited` = 有端口没约束，检查是否误删了 constraint 文件。

## 5. 烧写

1. TD 下载界面选 **AL-LINK-FT**，`Local Host`，端口 **5555**。
2. 点刷新（**可能要刷新两次**；出现 `OCCUPPIED` 就等几秒再刷新），直到认到器件型号 **PH1P35MDG324**。
3. 加载 4.4 生成的 `.bit`，下载。

## 6. 观察与记录（基线数据）

- 显示器应出现 **SC520 摄像头实时画面**（对着不同物体，画面跟随变化）。
- 按键调曝光：本例程按键在**扩展口**（`I_button[0]=N2`、`I_button[1]=J14`），**不是**板载 KEY1~4（D5/A9/B9/C7）——若按板载键没反应属正常。
- 记录一次综合报告：**LUT / DFF / ERAM / DSP 占用 + Fmax**，抄到 `memory/PROGRESS.md`，这是以后"我们比官方例程优化了多少"的对照。

## 7. 常见问题排查

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 认不到器件 | WinUSB 没装 / hwserver 没跑 | 回到第 2 步；刷新两次；等 `OCCUPPIED` 消除 |
| 黑屏 | HDMI 没插好 / 显示器没选对输入源 | 查 HDMI 线、显示器切到对应 HDMI 口 |
| 有画面但花屏/撕裂 | 摄像头排线松动、供电不足 | 断电重插排线；确认用 12V 供电 |
| 完全无图且 I2C 报错 | **摄像头不是 SC520**（例程带 sensor ID 校验 `S_cam_sensor_id_ok`，型号不符会配置失败） | 肉眼看摄像头丝印，确认 SC520CS |
| 画面暗/亮不自然 | 曝光/增益默认值 | 属正常，后续 P5 阶段做按键调参 |

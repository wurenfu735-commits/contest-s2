## 第 5 步 · 全流程编译（4~5 个按钮依次点，等绿灯）

在 **Flow/流程** 面板（或菜单 `设计 Design` 下同名命令）按序执行：

| 顺序 | 按钮 | 通过标志 |
|---|---|---|
| 1 | Read Design / 读取设计 | 无 ERROR，源文件全读入 |
| 2 | Optimize RTL / 优化RTL(综合) | 无 CRITICAL WARNING |
| 3 | Optimize Gate / 优化门级 | 无 ERROR |

## 第 7 步 · 验收对照（预期现象）

| 现象 | 判定 |
|---|---|
| 屏幕出现**八彩条**（白黄青绿品红蓝黑，各 160 列宽） | ✅ 自研测试图工作 |
| 画面底部 16 行状态带：上半段一条**白**色带（当前图案=彩条），下半段**全绿**（PLL 锁定） | ✅ 自检状态带工作 |
| 按扩展口 KEY1（N2）→ 图案切 棋盘16×16 / 渐变 / 灰阶 循环 | ✅ 交互工作 |
| 按 KEY2（J14）→ 回到彩条 | ✅ |
| 画面稳定不闪不滚 | ✅ 时序收敛 |

- 状态带下半段若为**红色**：PLL 未锁 → 检查 PLL 例化/reset 接法，贴 log。
- 彩条每条宽不对/横向滚动：像素时钟异常 → 贴 log。
- 屏幕无信号：查 TMDS 约束 4 行与 HDMI 接线。

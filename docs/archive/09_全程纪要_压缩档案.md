## 二、赛题要求速记（评分锚点）

- **基础 4 条（必做）**：B1 MIPI 采集+HDMI 实时显示；B2 FPGA 端≥1 种图像处理算法；B3 处理后画面稳定连续；B4 OSD 叠加且**必含"安路"Logo**
- **扩展 5 条**：①风格化/视觉增强(卡通化) ②目标检测+叠加结果 ③结合移动平台外部控制 ④性能优化(实时性/资源) ⑤自主创意。我们选 ①②④
- **进阶 5 条（高分项，按力气选）**：多算法切换/目标跟踪/延迟可视化/帧差运动检测/自动曝光白平衡
- **三条红线**：⚠️①提交算法**不得与官方例程 lab_ex1/2/3 相同** ②必须 **TD 6.2.1**（高版本不兼容） ③外扩不得含非安路 FPGA
- **自备设备**：带 HDMI 输入显示器（720p60 即可），HDMI1.4 纯铜线 ≤5m

4. **P1 自研**（按约定先做 GitHub 检索）：
   - 借鉴对象已声明（docs\07）：国一作品 [maojinxiang/FPGA-ANLU-National-First-Prize](https://github.com/maojinxiang/FPGA-ANLU-National-First-Prize)（上届同赛题国一，老平台 OV5640+SDRAM，**仅借 TPG 按坐标生成图案的结构 + 形态学膨胀思路**，算法核心自研）；[my_hdmi_device](https://github.com/splinedrive/my_hdmi_device) 只作学习不引入

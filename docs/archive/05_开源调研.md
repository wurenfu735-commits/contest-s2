## 二、重点对象 1：国一作品（同赛题、不同平台，**不能搬，只能借**）

**它是什么**：2025 年同赛事安路赛道国家级一等奖的完整开源（含 11MB 答辩 PPT + 源码 + 上位机 Python）。平台是**老平台**（AX301/EG4S20 + **OV5640 并口摄像头 + 外接 SDRAM**），与我们的 **HX1P35A + SC520 MIPI + 片内 DDR** 硬件差异大 → **整工程不可搬**，抄算法还有原创性风险（红线）。

**它有什么值得看（文件树实证）**：
- `color_bar.v` ← 彩条发生器（P1 直接对应物）
- `video_tpg_*.enc.v` ×6 分辨率（1024×768 / 1080p / 1280×1024 / 1280×800 / 1680×1050 / 800×600）← 各分辨率**测试图发生器**，按像素坐标产生图案
- `sobel_process.v`、`emboss_process.v`（浮雕）、`morphology_process.v`（形态学）← 它的算法三件套
- `frame_fifo_read/write.v`、`frame_read_write.v` ← SDRAM 乒乓帧缓存
- `hdmi/tmds/DVI transmitter` ← 经典 DVI/HDMI 风格发送链
- `udp_*` + `Host computer.py` ← UDP 网络遥控/传图 + 上位机（它的"远程交互"扩展）

### 借鉴点 / 我们的不同 / 用在哪

| 借鉴点 | 它怎么做 | 我们怎么做（不同） | 用在我们哪里 |
|---|---|---|---|
| 测试图发生器结构 | 按 (x,y) 坐标区间判色条/图案块 | 我们做 **720p 四合一测试图**：彩条+棋盘格+渐变+灰度级，再叠加**通链自检状态块**（PLL lock/DDR ready/帧计数画在画面上，能一眼看到链路健康），并可按键切换图案 | P1 colorbar_top |
| 彩条发生器写法 | 组合逻辑按列号选色（典型写法） | 结构参考，但图案集合+自检显示比它多一块可视化的"调试价值" | P1 |
| 形态学（膨胀/腐蚀） | 3×3 邻域取最大/最小 | P6 卡通化要"边缘加粗"，用同思路的 3×3 dilation，但接在我们自己的自适应边缘后面 | P6 卡通化 |
| 浮雕算法 | 对角差分+灰度偏移 | 只作为"风格化滤镜"候选清单项，非主线；主线仍是自适应阈值边缘检测 | P6 候选 |
| UDP 远程 + 上位机 | 千兆网传图遥控 | ⚠️ 4 周冲刺**不做**（超范围）；写入答辩"后续扩展"话术 | 答辩展望 |

**红线自查**：仅借鉴"测试图/形态学的**结构思路**"，所有算法核心判决逻辑（自适应阈值、双阈值迟滞）均为自研写法；不复制其 sobel/emboss 源码。

## 三、重点对象 2：my_hdmi_device（107 星，ISC 许可）

- 是什么：多平台 TMDS(HDMI) 发送实现（DDR/SDR 传输、8b10b 编码细节）。
- 我们的决策：**只当物理层学习材料，不引入工程**。理由：赛题例程自带的 `hdmi_tx + lane_lvds_10_1 + PLL(74.25M/371.25M)` 已经编译、布线、上板、0 时序违规验证过（P0 基线）；换轮子有风险无收益。P1 的 HDMI 链路**原样复用例程**。

## 五、常见问题速查

| 现象             | 原因                     | 处理                                      |
| -------------- | ---------------------- | --------------------------------------- |
| 编译报 `BIT-8123` | 有端口没约束                 | 检查约束集只留 colorbar_top.adc，顶层端口与它一一对应     |
| 状态带下行是红色       | PLL 没锁（clock 输出异常）     | 检查 PLL 输出/复位接法，贴 log                    |
| 按键没反应          | 按键在扩展口 N2/J14，不是板载 KEY | 换扩展口；确认 PULLUP 约束                       |
| 黑屏、有背光         | HDMI 无信号               | 查 I_video_rgb_enable=1、de/vs 接线、TMDS 约束 |

## 二、P0 → P1 的对接逻辑（先懂"为什么接着做这个"）

```
P0（已完成）:  摄像头 ──MIPI──▶ [采集链+ISP] ──▶ [DDR帧缓存] ──▶ [HDMI显示链] ──▶ 显示器   ✅整条链路
P1（现在做）:  （去掉摄像头）  [内部测试图发生器TPG] ──▶ [DDR帧缓存] ──▶ [HDMI显示链] ──▶ 显示器

关键点：P1 把"采集"和"显示"拆开，先单独证明"显示半条链 + DDR + HDMI"没有问题。
以后你们所有自研（算法、OSD）都先在 P1 的测试图上验证，就不必每次依赖摄像头这个变量。
```

对接点（技术事实）：同一个 TD 工程、**同一套引脚约束**（pin.adc 不动）、**同一条 HDMI 发送链**，唯一变化 = 数据源从"摄像头"换成"内部测试图发生器"。官方包里有配套现成 .bit，正好当 P1 的验证起点。

## 三、P1 第一步 · 软件操作（烧官方现成"测试图"bit，零代码）

**目的**：不碰代码，先烧两个官方测试图，确认"无摄像头也能出图"。

1. 打开 TD 6.2.1，**不需要打开工程**，直接点工具栏**下载按钮**（Download/下载图标）。
2. 下载线选择：**AL-LINK-FT**（或 AlinkFt），`Local Host`，端口 **5555**。
3. 点**刷新**（可能要两次；出现 `OCCUPPIED` 等几秒再刷），直到认到器件 **PH1P35MDG324**。
4. 选 bit 文件（两个候选，先 A 后 B）：

   - **A（推荐先烧）**：`...\td_project\camera_to_dsi_display_Runs\best_result\camera_to_dsi_display_hdmi_core_tpg_vic0_75m.bit`
     → "TPG" = 测试图发生器，"vic0_75m" 指 720p/75MHz 像素时钟，**和我们项目核心分辨率一致**。
   - **B（第二个烧）**：`...\best_result\camera_to_dsi_display_1080p_colorbar_test.bit`
     → 1080p 彩条测试。

5. 下载完成后，**不需要插摄像头**，直接看显示器。

**记录要求**（烧完告诉我这 3 点）：
- A 是彩条还是纯色/方格？颜色对不对？（标准彩条是白黄青绿品红蓝黑 8 条）
- 画面稳不稳？有没有闪/撕裂？
- 显示器 OSD 里显示的**输入分辨率**是多少？（验证 720p vs 1080p）

## 四、P1 第一步 · 硬件连接（无摄像头版本）

| 顺序 | 动作 |
|---|---|
| 1 | 电源开关 **OFF** |
| 2 | **摄像头可以不插**（就让它空着） |
| 3 | 插 HDMI 线（板 → 显示器） |
| 4 | 插 12V 电源 + USB 转 JTAG 线（连电脑） |
| 5 | 开电源 |
| 6 | TD 里按第三节第 1~5 步下载 |

**现象对照表**（出问题时先看这个）：

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 显示器无任何图像 | HDMI 线松 / 显示器输入源没切 | 重插线；显示器切到对应 HDMI 口 |
| 屏幕一直黑但有背光 | 下载没成功（器件没认到） | 回到第三节第 3 步，刷新两次 |
| 彩条缺色/顺序怪 | 正常现象不同模式（先记录，别急着修） | 拍照记录告诉我 |
| 画面闪/撕裂 | HDMI 接触或线材差 | 换条好线（1.4 以上纯铜） |

## 四、今天需要注意并记忆的点

**A. 技术坑（已写入 MEMORY 第五节）**
1. **沙箱档位 = 执行能力总开关**：pwsh 报 `0xC0000142` → 先查文件策略是否为 `workspace-write`（切 `danger-full-access` 即恢复）。
2. **约束属性必须匹配端口方向**：`input` 脚不能带 `DRIVESTRENGTH`（官方 I_button 是 inout 才可以）→ 否则 `USR-8409`。
3. **视频通路有两套坐标**：`hcnt/vcnt` 是含消隐的整幅计数，画面坐标 = hcnt−260 / vcnt−25；彩条 8 分列每段 160 列用比较链。
4. **ModelSim 10.5 = 只认 Verilog-2001**：禁 `longint`、块内声明赋初值、数字位选 `264[4]`、`%0s`。
5. **tb 三个自坑**：多 initial 共享变量竞争 → 改单 initial 顺序；单拍采样对不准寄存延迟 → 用 4 拍窗口；注释写了没做的检查 → 删。
6. **中文/emoji 输出必崩 GBK**：Python 与 ModelSim 都要 `PYTHONIOENCODING=utf-8` / 控制台 UTF-8。
7. **HF 模型下载 401** → `HF_HUB_DISABLE_XET=1`（+ `HF_ENDPOINT=https://hf-mirror.com`）。
8. **faster-whisper 与 PyAV 19 冲突**：绕法是 ffmpeg 抽 16k wav → 数组喂 `transcribe()`，跳过 `av.open`。（降级 av<15 在本机无 cp313 wheel，走不通。）
9. **视频分析捷径**：ffmpeg 抽帧 → AI 读图（比装一整套 ASR/VLM 管线快得多）。
10. **按键目前约束在扩展口 N2/J14** → 板载 KEY1~4 按不到，v2 必须改到 D5/A9。

**B. 工作方法与约定**
1. **对照实验优先**：疑难问题先找"同机其它工具是否正常"这类对照，能瞬间缩小范围（今天最大的教训）。
2. **产出必须落盘再声明**，绝不虚报。
3. **注释与实现必须一致**；代码注释去 AI 腔（只写工程实话）。

5. **阶段自检三查**（目标/红线/路线）不可省。

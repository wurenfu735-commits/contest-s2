## 第一部分 · 赛题到底要什么（核实口径）

### 1.2 评分标准（2.6，4 条）

1. 基础功能完整 → 上面 4 条
2. **图像处理算法效果** → 需客观指标（PSNR/检出率/漏检率），不能只有"看着还行"
3. **扩展与创新** → 见下
4. **系统稳定性**：长期运行无花屏、无缓存溢出、**光线剧烈变化时工作正常** ← 我们目前零实测

### 1.3 扩展的真实结构：2 个基础扩展 + 5 个高阶挑战（不是"5 条"）

## 第二部分 · 技术路线五层（每层四要素）

### T1 通路层 —— 采集到显示的稳定链路

**要干什么**：B1 + B3。让画面稳定、连续、可测量。

**可以怎么干**：
- **保留现有**，不动结构：MIPI D-PHY → CSI 解包 → RAW10 → demosaic → awb → 算法插入点 → 96→128 → DDR 四缓冲 → hdmi_mixer → hdmi_tx
- 只补两件事：①**帧率 / 丢帧 / 错误计数器**（FIFO 溢出、MIPI 误码、坏帧回退各挂一个 32 位计数）②恢复上电自检标志

**怎么算干好**：
| 项 | 标准 |
|---|---|
| 帧率 | 60 s 计数 **3600 ± 2 帧** |
| 长稳 | 连续 30 min 无花屏、无撕裂、无卡死 |
| 光变 | 开灯/关灯/手电直照交替 **10 次**，画面不失控 |
| 拔插 | 断电拔插摄像头 3 次，均能恢复 |
| 时序 | WNS > 0 |

**注意什么**：绝不碰 DDR 133.33M 域（新逻辑只放 74.25M / 103.52M）；DDR 用长突发；MIPI 误码要有坏帧回退。

---

### T2 像素算法层 —— 自研算法 + 风格化

**要干什么**：B2（已有）+ **基础扩展① 风格化**。

**可以怎么干**：
1. **保留**：`edge_adaptive_96` 的判决体系（自适应阈值 + 因果迟滞）——这是差异化核心
2. **优化**：5×5 均值 → **3×3 中值**（保边去噪）；分段 FLOOR → **局部均值归一化** `阈值 = base + k×(局部均值 − 全局均值)`，**复用已算出的 5×5 均值窗口，零额外 ERAM**
3. **新增卡通化**：颜色量化（每通道保留高 4 bit）+ 边缘 3×3 膨胀 + 按位融合
4. **共用一套窗口生成器**：卡通化与检测都只需 3×3 邻域，共用行缓存是塞进预算的唯一办法

**怎么算干好**：
| 项 | 标准 |
|---|---|
| 卡通化 | 明显动画风：色块平滑 + 黑色描边，肉眼可辨 |
| 边缘 | 雪花肉眼减少（与 v5 位流并排对比拍照） |
| 仿真 | 与黄金模型逐像素 **0 误差** |
| 成本 | 卡通化 ≤450 slice；中值改造 ≤150 slice |

**注意什么**：不能照抄官方 Sobel（红线）；算法必须**固定延迟**（96bit 通路 `O_tready` 直通，无反压）；新逻辑只放 74.25M/103.52M 域。

---

### T3 检测识别层 —— 最大缺口，从零建

**要干什么**：**基础扩展②**（检测识别 + 叠加结果与文字）+ **高阶(2)**（跟踪 + 坐标叠加）。

**可以怎么干**（按顺序）：
1. **RGB→HSV 判色**（在 T2 侧统一转换一次，供所有算法共用）
2. **形态学开运算**去孤立噪点
3. **区域聚合：网格化投影**（8×8 或 16×16 格独立统计命中数与局部质心，相邻格合并）
   → **不要用整帧行列投影**：两个同类物体会被框成一个大框（见 `docs/24` 失误 2）
   → 有余力再升级为单遍连通域 CCL，两者特征输出接口设计成一致，升级不改上层
4. **质心 / 包围盒**：除法直接用 DSP（31 个闲置），不必做近似
5. **跟踪**：质心一阶 IIR + 最近邻 + 丢帧保持
6. **去抖**：连续 3 帧命中才确认输出
7. **★帧对齐**：检测在 103.52M 域、显示在 74.25M 域、中间隔 DDR（1~2 帧）→ 显示域用 **vsync 同步的 k 级寄存器延迟链**对齐（几十个 FF，最省）

**怎么算干好**：
| 项 | 标准 |
|---|---|
| 跟随 | 目标匀速摆动，框与边缘偏差 **≤2 px**，且不随速度增大（验证帧对齐生效） |
| 多目标 | 两个同类物体**分别成框**，不粘连 |
| 稳定 | 静止目标连续 300 帧，类别不跳变、坐标抖动峰峰 ≤2 px |
| 去抖 | 单帧噪声不产生"幽灵目标" |
| 实时 | 端到端延迟 ≤3 帧（50 ms） |
| 成本 | ≤850 slice + 2~3 ERAM |

**注意什么**：帧对齐**必须在做检测的同时做**，否则返工的是整个数据通路；ERAM 预算留够；检测结果与显示画面必须同帧。

---

### T4 呈现叠加层 —— Logo、状态、坐标、延迟

**要干什么**：B4（Logo）+ 高阶(1) 状态显示 + 高阶(3) 延迟可视化。

**可以怎么干**：
1. **切自研 OSD**（定义 `OSD_SELF_DEV`）：78.6% → ~69%，WNS +101ps → +787ps。**这是全部扩展的入场券**
2. **统一数值通道**：做一个通用数值渲染接口，帧率 / 延迟 ms / 模式名 / 坐标 / 计数都走它，以后加指标不改结构
3. Logo 像素数据沿用官方 ROM（主办方标识），**排版与渲染逻辑自研**
4. 坐标参数化（便于应急缩到 96×32）

**怎么算干好**：
| 项 | 标准 |
|---|---|
| Logo | 清晰可辨、位置正确（B4 硬性项） |
| 数值 | 帧率数字与独立计数器**交叉验证一致**；延迟 ms 与实测吻合 |
| 稳定 | 600 帧内无闪烁、无错位、无残影 |
| 对齐 | OSD 框与目标边缘 ≤2 px |
| 成本 | 自研 OSD 省约 2100 slice；数值通道 ≤200 slice |

**注意什么**：OSD 必须在**像素域**、`hdmi_mixer` 之后，**绝不能进 `isp_top`**（否则 Logo 会被自己的边缘算法吃掉）；坐标要区分有效区与消隐区。

---

### T5 交互联动层 —— 切换、运动检测、外设

**要干什么**：高阶(1) 切换平稳 + 高阶(4) 帧差运动检测 + 创意联动。

**可以怎么干**：
- 切换：`mode_ctl` 已有，**关键是在帧边界（vsync）切换**，这是"力求平稳"的考点
- 帧差：存**降采样前一帧**（160×90 灰度 ≈ 6 ERAM），逐块相减+阈值+统计运动块数
- 联动：蜂鸣器 C12（SW5 拨 ON）+ 数码管（SW6 拨数码管）+ UART（J1/H1）；有余力上以太网（板载 YT8511，`assets` 已有 UDP 上位机参考）
- 按键引脚：**N2/J14（扩展口）→ D5/A9/B9/C7（板载）**

**怎么算干好**：
| 项 | 标准 |
|---|---|
| 切换 | 无撕裂（**半帧都不许**）、响应 ≤200 ms、无死机 |
| 运动 | 挥手出区域框 + 计数递增 |
| 外设 | 命中即发声/计数，响应 ≤200 ms |
| 成本 | 切换 ~200 slice；帧差 ~300 slice + 6 ERAM；联动 ~100 slice |

**注意什么**：切换必须帧边界；SW5/SW6 演示前确认拨对；帧差是最独立的项，**资源紧张时第一个砍它**。

## 第三部分 · 现状判定：保留 / 优化 / 重做 / 新增

### ✅ 保留（做得对，不要动）

| 项 | 理由 |
|---|---|
| P0 全链路（MIPI→ISP→DDR→HDMI 720p60） | 稳定跑通、时序 0 违规 |
| 96bit / 4 像素算法接口与插入点 | 与官方 lab_ex2 对齐，位置正确 |
| **`edge_adaptive_96` 的判决体系**（自适应阈值 + 因果迟滞） | 与官方"固定阈值"的核心差异，**不要因残雪未解而推翻** |
| 黄金模型 + 逐像素验证 + `run_tb_96.ps1` | 质量保证体系，队伍里少见，答辩可讲 |
| 位流台账 + SHA256 + 一键编译判读 | 工程规范，防混淆 |
| `mode_ctl` / `cdc_mode_sync` / `debounce_btn` | 74.25M 域 + 独热码跨域 + 帧锁存，设计正确 |
| 自研 `osd_overlay.v`（待启用） | 优于官方整像素替换 |
| 官方 Logo ROM 数据 | 主办方标识，赛题要求显示它 |
| docs / memory 体系 | 信息密度高，继续维护 |

### 🔧 优化（改进，不推翻）

| 项 | 改法 | 收益 |
|---|---|---|
| **官方 OSD → 自研** 🔴 | 定义 `OSD_SELF_DEV` | 省 ~2100 slice，WNS +101ps→+787ps |
| **残雪治理层级** | L2 暗区增益限幅 + L3 改 3×3 中值 + 局部均值归一化；**停止调分段地板** | 治本，且不再反复 |
| 5×5 均值 → 3×3 中值 | 保边去噪 | 边缘更清晰 |
| 补 `<SDC_FILE>` 段 | `.al` 引用 sdc | STA 21% → ~43% |
| **闲置 31 个 DSP 用起来** | HSV max/min、质心除法、坐标缩放 | 用 DSP 换紧缺的 slice |
| 帧率/丢帧/错误计数器**提前到阶段 0** | 别等阶段 3 | 稳定性测试与答辩都要它 |
| 文档数据统一 | 以 `需求文档.md` §1.3 为唯一权威 | 避免答辩被问穿 |
| 更正过时环境记录 | 本机 ModelSim / pwsh 7 均可用 | 不浪费仿真能力 |
| `check_build.ps1` 日志路径 | 读 `*_Runs/syn_1`、`phy_1` | 避免假结论 |
| git 推送 | 本地 5 M + 多个新文件未提交 | 防多机冲突 |

### ❌ 重做 / 换方案（现有方案有缺陷）

| 项 | 现状 | 换成 |

## 第六部分 · 一句话执行纪律

**先腾空间，再谈功能；黄金模型先行，仿真不过不上板；每加一项实测一次资源与时序；每个功能先问"花多少 slice、换什么分"；改完立刻 push。**

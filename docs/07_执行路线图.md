# 13 · 执行路线图 + "我们到底在干什么"（大白话版）

## 第一部分：用一条"流水线"讲清我们在干什么

### 我们的作品本质 = 在 FPGA 里造一条**实时图像加工流水线**

```
📷 摄像头  →  [进货口]  →  [初加工]  →  [仓库]  →  [★加工车间★]  →  [贴标]  →  [出货口]  →  显示器
   原料         MIPI         ISP          DDR        自研算法         OSD       HDMI
              (排线)     (去马赛克/白平衡) (帧缓存)   (我们的核心)   (安路Logo)  (TMDS)
```

**这条流水线的特点**：原料（画面）每秒 60 帧不停地流进来，每一帧都要在 **16.7 毫秒内**加工完，一秒钟都不能卡。

**评委要看的就是两件事**：

1. 这条流水线**能不能稳定跑**（跑不稳 = 功能再花哨也没用）
2. 你的**加工车间（算法）**&#x505A;得有没有水平、够不够多、够不够快

### 我们做过的每一件事，处在流水线的哪个位置、起什么作用

| 我们做的事                | 大白话解释                  | 起什么作用                                                                                   |
| -------------------- | ---------------------- | --------------------------------------------------------------------------------------- |
| 读资料、确认摄像头是 SC520     | 确认"进货口"对接什么型号的原料       | 型号错了整条线跑不起来（事实证明这批资料里有两套例程）                                                             |
| **P0：跑通官方三个例程**      | 拿官方给的成品流水线**空转一遍**     | ①证明设备没坏（是我们的代码问题还是板子问题，一测便知）②抄下官方的"性能参数"当**对比基准**（他们占 58% 资源，我们占 4.56%）                 |
| **P1：自研彩条测试图**       | 造一套"**假原料**"（彩条/棋盘/渐变） | ⭐ **最关键的地基**：以后调试加工车间时**不用每次真喂原料（摄像头）**——用假原料就能验证算法对不对，效率高十倍；出了问题也能立刻分辨是"进货口坏了"还是"车间坏了" |
| **P2：自研边缘检测算法**      | 造我们自己的**加工车间**（核心技术）   | 这是**唯一能拿分的地方**（官方算法不能用，红线）；也是答辩时讲原理的主体                                                  |
| Python 黄金模型          | 用软件写一份"**标准答案**"       | 硬件算出来的每一帧，和软件标准答案**逐像素比对**——这是"我们做对了"的铁证，比"看起来对"强一百倍                                    |
| **P4：OSD 叠加安路 Logo** | 在成品上**贴品牌标签**          | 赛题硬性要求（必须含"安路"标识），也是加分展示位                                                               |
| 修 DSH 环境 / 装 ffmpeg  | 给**助手（AI）**&#x914D;工具  | 让 AI 能自己动手（复制文件/跑仿真/看视频），把人的时间省下来做需要判断的事                                                |
| 分析国一视频与 PPT          | 学"**怎么把作品讲给评委听**"      | 评委原话："优质展示视频占晋级概率 70%"——比技术本身还重要                                                        |
| GitHub 调研（8 个项目）     | 看别人**怎么造加工车间**         | 避免重复造轮子，且能借鉴"视觉效果强"的算法（热力图/目标检测准星）                                                      |
| 写文档 + 记忆库            | 给团队留**交接班笔记**          | 让三个人（和 AI）随时能接上别人的活，不会"只有某一个人懂"                                                         |

### 一句话总结"我们在干什么"

> **我们在给一条实时流水线造"加工车间"：先让流水线跑通（P0），再造假原料方便调试（P1），然后一个接一个地造出又快又酷的加工机（算法），最后贴上标签、拍成视频讲给评委听。**

**为什么必须这样做而不是"直接改官方例程"**：

- 官方例程的**硬件管道**（进货口/初加工/仓库/出货口）涉及安路芯片的专用电路，自己从零写要 3 周以上——**直接复用**
- 官方例程的**算法**（加工方式）是固定的、也是**禁止照抄**的（红线）——**必须自己造**
- 所以准确说：**"用官方修好的路，跑我们自己的车"**
